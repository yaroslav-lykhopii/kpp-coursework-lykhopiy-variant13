## Опис проєкту

Клієнт-серверна кросплатформена інформаційна система для обліку технічних заявок у готельному комплексі. Система дозволяє вести облік номерів, фахівців, створювати заявки на усунення несправностей, контролювати їхній життєвий цикл та розраховувати інтегральний показник впливу.

Проєкт складається з двох окремих Maven-модулів:
*   `server` — серверна частина (Servlet API, Service, DAO, JDBC, MySQL);
*   `client` — графічний JavaFX-клієнт.

Взаємодія між клієнтом та сервером відбувається через HTTP/JSON.

---

## Використані технології

*   Maven
*   JavaFX 21.0.2
*   Apache Tomcat 9.x (Servlet API 4.0.1)
*   MySQL (Connector/J 9.7.0)
